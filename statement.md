# Problem Statement
Financial institutions receive thousands of loan applications daily, making manual evaluation time-consuming and prone to human bias. The objective of this project is to automate the loan eligibility process by predicting approval status based on applicant demographic and financial details.

# Scope of the Project
The system analyzes historical loan data to identify patterns correlating to loan default or successful repayment. It provides an interactive web application where users can input new applicant data and receive an instant, machine-learning-backed approval verdict.

# Target Users
* Bank evaluating officers seeking secondary validation for loan approvals.
* Financial analysts auditing the historical accuracy of loan underwriting.
* Applicants wanting to check their pre-approval probability.

# High-Level Features
* Automated data preprocessing and null-value sanitization.
* Predictive modeling using a Random Forest Classifier algorithm.
* Real-time interactive user interface for instant inference.
